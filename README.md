## הבעיה

כל מפקד מילואים מכיר את הכאב: לסדר יציאות הביתה ל-10, 15, 20 חיילים — עם אילוצים אישיים, מינימום כוח אדם בבסיס, הגינות בחלוקה — וזה לוקח שעות של אקסלים ובלאגן.

## הפתרון

מייצר לוח תורנויות אוטומטי תוך שניות:

- **חלוקה שוויונית** — אלגוריתם אופטימיזציה שמחלק ימי בסיס שווה בשווה
- **אילוצים אישיים** — חייל צריך להיות בבית ביום מסוים? סימון פשוט וזה נלקח בחשבון
- **כללים גמישים** — מינימום חיילים בבסיס, מקסימום ימי בית ברצף, מינימום ימי בסיס ברצף
- **רצפים הגיוניים** — בדרך לבסיס → בבסיס → יוצא הביתה (לא קפיצות אקראיות)
- **ייצוא לתמונה** — שליחה ישירה לקבוצת וואטסאפ של הפלוגה
- **רץ בדפדפן** — לא צריך התקנה, לא צריך שרת, עובד מהנייד

## טכנולוגיות

| שכבה | טכנולוגיה |
|------|-----------|
| Frontend | React 18, TypeScript |
| אלגוריתם | Constraint-based greedy scheduler with balancing optimization |
| Build | Vite |
| Deploy | Vercel (static) |

### על האלגוריתם

האלגוריתם פועל בשני שלבים:

1. **שיבוץ ראשוני (Greedy Scheduling)** — עובר יום-יום, מקצה חיילים לבסיס תוך כיבוד אילוצים (תאריכים חסומים, מינימום בבסיס, רצפים). בכל יום נבחרים המועמדים עם הכי פחות ימי בסיס עד כה — כדי לשמור על הוגנות.

2. **איזון (Balancing Pass)** — לאחר השיבוץ הראשוני, האלגוריתם מנסה להחליף רצפים שלמים בין חיילים כדי לצמצם את הפער בימי שירות. ההחלפה מתבצעת רק אם כל האילוצים עדיין מתקיימים.

**Complexity:** O(n × d × d) כאשר n = מספר חיילים, d = מספר ימים.

## הרצה מקומית

```bash
cd frontend
npm install
npm run dev
```

נפתח ב-`http://localhost:5173`

## Deploy

```bash
cd frontend
npm run build    # יוצר תיקיית dist
```

העלו את `dist` ל-Vercel / Netlify / GitHub Pages.
